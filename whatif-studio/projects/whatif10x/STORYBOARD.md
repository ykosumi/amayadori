# もしも あなたの動きが 10倍 速くなったら？ — 台本・出典・ストーリーボード v2 (フラット2D版・承認待ち)
9:16 / 24fps / 約80秒。**承認前にアセット生成なし**。ボイスは Voicepeak(所有) を第一候補。

## 前提 (ラベル付き)
- [A1] 「10倍」＝移動速度と動作速度が10倍。周囲の世界・電車・エレベーターの速度は変わらない。
- [A2] 歩行 5km/h(約1.4m/s) を基準 → 10倍=50km/h。※一般的な目安、出典は承認後に追加。
- [A3] 空気抵抗は CdA=0.5m² と仮定(直立した人の概算)。ρ=1.2kg/m³。
- [A4] 路面摩擦係数 μ=0.7(乾燥路面の標準値)、反応(知覚→行動)時間 1.0秒。
